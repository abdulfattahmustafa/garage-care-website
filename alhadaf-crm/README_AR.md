# نظام إدارة علاقات العملاء — معرض الهدف الأميز

نظام CRM خاص فيك، فيه كل بيانات عملائك اللي اشتروا من المعرض، مع تذكيرات تلقائية لمتابعة ما بعد البيع وتبليغ المبيعات (مطلوبة رسميًا لمعيار "إدارة علاقات العملاء" في برنامج جميل بلس 2026).

---

## 1. كيف تشغّل النظام أول مرة (خطوة بخطوة)

### المتطلبات
لازم يكون عندك برنامج **Node.js** مثبت على جهازك (نسخة 18 أو أحدث). لو ما عندك، حمّله من:
`https://nodejs.org` (اختر النسخة LTS).

### خطوات التشغيل

افتح **Terminal** أو **Command Prompt** داخل مجلد المشروع (`alhadaf-crm`) ونفّذ الأوامر التالية بالترتيب:

```bash
# 1) انسخ ملف الإعدادات
cp .env.example .env

# على ويندوز استخدم بدلها:
copy .env.example .env

# 2) ثبّت المكتبات المطلوبة (مرة وحدة فقط)
npm install

# 3) أضف بيانات تجريبية عشان تشوف شكل النظام (اختياري)
npm run seed

# 4) شغّل النظام
npm start
```

بعدها افتح المتصفح على:

```
http://localhost:3000
```

كلمة المرور الافتراضية: **alhadaf2026** (غيّرها فورًا — شوف القسم التالي).

> لإيقاف النظام: ارجع لنافذة الـ Terminal واضغط `Ctrl + C`.
> لتشغيله مرة ثانية لاحقًا: افتح Terminal داخل المجلد ونفّذ `npm start` فقط.

---

## 2. كيف تغيّر كلمة المرور

1. افتح ملف `.env` (بأي محرر نصوص بسيط مثل Notepad).
2. غيّر القيمة اللي بعد `APP_PASSWORD=` إلى كلمة المرور اللي تبيها.
3. احفظ الملف.
4. أوقف النظام (`Ctrl+C`) وشغّله من جديد (`npm start`).

---

## 3. حذف البيانات التجريبية قبل إدخال بياناتك الحقيقية

النظام يجي فيه 4 عملاء وهميين للتجربة فقط. لحذفهم:

```bash
npm run clear-demo
```

هذا الأمر يحذف **العملاء التجريبيين فقط** ولا يمس أي بيانات حقيقية أدخلتها.

---

## 4. كيف تاخذ نسخة احتياطية

من القائمة العلوية اضغط **"نسخة احتياطية"** — بينزل لك ملف JSON فيه كل بياناتك (العملاء، سجلات التواصل، إجراءات SOP). احتفظ بهذا الملف في مكان آمن (مثلاً جوجل درايف) وكرر هذا كل فترة (أسبوعيًا مثلاً).

### كيف تسترجع نسخة احتياطية
من القائمة اضغط **"استعادة"**، اختر ملف الـ JSON اللي نزّلته سابقًا، واضغط "استعادة البيانات".

⚠️ **تنبيه مهم:** الاستعادة تستبدل كل البيانات الحالية بالكامل بما هو موجود في الملف. تأكد إنك تبي هذا فعلاً قبل ما تضغط.

---

## 5. تصدير البيانات إلى Excel

من صفحة "العملاء" اضغط **"تصدير النتائج Excel/CSV"** — ينزّل ملف CSV يفتح مباشرة في Excel، ويحترم نفس الفلاتر والبحث المطبّق وقتها (يعني تقدر تصدّر بحث معيّن بس، أو كل العملاء).

---

## 6. التذكيرات التلقائية

- **متابعة ما بعد البيع:** يظهر في "لوحة المتابعة" (الصفحة الرئيسية) تلقائيًا بعد 24 ساعة من وقت التسليم المسجّل، لو ما سجّلت نتيجة المتابعة بعد.
- **تبليغ المبيعات:** الموعد النهائي يُحسب تلقائيًا (نهاية الشهر التالي لشهر البيع). يظهر بالأصفر لو باقي أسبوع أو أقل، وبالأحمر لو فات الموعد.
- **زر واتساب جماعي:** من الصفحة الرئيسية، زر "إرسال ملخص المستحقات للفريق" يفتح واتساب برسالة جاهزة فيها كل المتأخرات، تقدر ترسلها لقروب الفريق مباشرة.

---

## 7. كيف تنشر النظام على الإنترنت لاحقًا (اختياري)

النظام حاليًا يشتغل محليًا على جهازك فقط. لو حبيت تشغّله من أي مكان (من الجوال بره الشبكة، أو يستخدمه أكثر من موظف بنفس الوقت)، عندك خيارين بسيطين:

**الخيار الأول (الأسهل) — استضافة سحابية مجانية بسيطة:**
ارفع مجلد المشروع على منصة مثل Render أو Railway (تدعم Node.js + قاعدة بيانات SQLite على قرص دائم). اطلب من أي مبرمج أو من Claude Code مساعدتك بخطوات الرفع.

**الخيار الثاني — سيرفر خاص (VPS):**
لو عندك سيرفر (مثلاً من STC Cloud أو أي مزود)، تقدر ترفع المشروع عليه وتشغّله بأمر `npm start` مع أداة مثل `pm2` تخليه يشتغل باستمرار حتى لو أعدت تشغيل السيرفر.

في الحالتين، لا تنسَ:
- تغيير `APP_PASSWORD` و `SESSION_SECRET` في ملف `.env` لقيم قوية وسرّية.
- أخذ نسخة احتياطية دورية من ملف `data/alhadaf.db`.

---

## 8. أسئلة شائعة

**س: نسيت كلمة المرور؟**
افتح ملف `.env` وشوف قيمة `APP_PASSWORD`، أو غيّرها بنفسك مباشرة.

**س: البيانات تضيع لو أغلقت الجهاز؟**
لا. البيانات محفوظة في ملف `data/alhadaf.db` على قرصك، تبقى موجودة حتى لو أغلقت النظام أو أعدت تشغيل الجهاز. فقط لا تحذف مجلد `data`.

**س: أقدر أستخدمه من جوالي وأنا داخل نفس شبكة الواي فاي حق المعرض؟**
نعم. شغّل النظام على أي جهاز كمبيوتر متصل بنفس الشبكة، واعرف رقم الـ IP الخاص فيه (مثلاً `192.168.1.10`)، وافتح من جوالك: `http://192.168.1.10:3000`.
